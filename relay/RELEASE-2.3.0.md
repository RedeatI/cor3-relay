## 从 2.2.1 升级到 2.3.0

这次主要修了游戏页长时间放在后台后，市场刷新一直等、日志停在旧记录，以及小游戏进度迟迟不动的问题。

- **市场委托**　游戏回报新的委托列表后，即使另一次后台读取随后更新了缓存时间，插件也能记住这一轮刷新。当前任务结束后再检查，避免漏跑或重复开一轮。重新进游戏时，旧页面留下的“正在执行”标记会与当前页面核对。
- **后台读取**　进入游戏时先读雇佣兵名单，报价留到确实要用时再查。取消刷新会同时清掉对应的等待，旧回执不会结束新请求。系统校时往回调，也不会让新请求多等一段时间。
- **解密小游戏**　ICE Wall 会等游戏确认进度后再看下一组图形，终端小游戏也会核对当前回合。遇到画面没切换或结果还没回来的情况，可以在状态里看到原因。
- **Daily 和远征**　Daily 会识别旧页面留下的占用，手动关闭后，迟到的定时回执不会再把它排回去。远征和无人机能读取新版事件里的风险、收益变化；已选过的雇佣兵事件会略过。
- **状态日志**　长时间挂机也能继续看到新记录。后台和弹窗同时写日志时会顺序保存；打开状态面板时，其余组件无需反复复制整份日志。清理旧记录对当前读取的影响也更小。

**更新方法**　下载对应浏览器的 ZIP。等当前批次结束，把压缩包里 `extension` 的内容覆盖到原先加载的目录，在扩展管理页点「重新加载」，再刷新游戏页。沿用原目录可以保留原有设置。

首次安装时，解压后在扩展管理页开启开发者模式，选择「加载已解压的扩展程序」，选中 `extension` 文件夹。

Chrome 和 Edge 各通过 600 项本地回归测试。另在两个浏览器的独立配置中验证了日志清理和中断后的写入恢复。真实账号连续过夜挂机仍待验证。

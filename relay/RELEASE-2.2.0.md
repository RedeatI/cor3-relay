## 这版有什么变化

- **打开 C3 就能看配装。** 硬件按 CPU、GPU、内存和电源分类，点选就能对比当前装备和候选装备的参数。软件按用途分类，安装前可以看到能力范围和资源需求。
- **反复打开面板更省请求。** 配装和 Daily 的成功读取最多复用 5 分钟，远征和无人机复用 1 分钟。市场会看自己的刷新时间，到点就重新核对。需要马上看最新数据时，仍可点刷新。
- **网络不稳时少打扰游戏。** 某个市场一直返回旧数据时，插件会逐步延长该市场的重试间隔，其他市场照常检查。修复了一个连接过期会把其他游戏连接一起断开的问题。
- **Daily 和无人机状态更准确。** 重复的登录通知合并为一次 Daily 读取，换号前发出的请求即使晚到，也不会盖掉新会话的数据。收到无人机维修回执后会重新读取状态。
- **语言跟随你的选择。** 在浏览器右上角打开插件，滑到底部即可切换 CN / EN。选一次就会记住，左下角 C3 也跟着切换。
- **会话凭据只在当前游戏页使用。** 确认账号后，插件会清理该账号旧版保存在本地设置里的 Daily 登录凭据。

## 下载与更新

下载对应浏览器的 Chrome 或 Edge 压缩包。首次安装时，解压后在扩展管理页选择“加载已解压的扩展程序”，指向包里的 `extension` 文件夹。

已经装过公开版的用户，把新包中 `extension` 的内容覆盖到原来的插件目录。等当前任务结束，再到扩展管理页点“重新加载”，然后刷新游戏页。沿用原目录和扩展身份，可以继续使用原有设置。

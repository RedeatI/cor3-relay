## 从 2.1.0 升级到 2.2.0

从 2.1.0 更新后，换装时可以直接对比参数，快速重开 C3 可以接着看上次的数据。这次还修复了市场委托漏领奖和部分文件解密被跳过的问题。上一个公开版本是 [COR3 Relay 2.1.0](https://github.com/RedeatI/cor3-relay/releases/tag/v2.1.0-relay)。

### C3 面板与配装

- **选装备时就能看参数。** CPU、GPU、内存和电源分开列出，每张卡片显示关键数值。选中候选硬件，可以和当前装备逐项对比。软件按入侵、解密、搜索等用途分类，列表直接显示能力范围和安装状态，展开后还能看资源需求和整机占用。
- **中英文切换统一了。** 首次使用跟随浏览器语言。在右上角插件弹窗底部选择 CN 或 EN，C3、插件子菜单和日志查看器会一起切换，并记住选择。调整了窄窗口下英文按钮的换行、对齐和任务进度文字。
- **查看任务进度更轻了。** C3 收起时，自动化助手可以直接读取当前页面的执行项、排队数和进度，无需展开面板或重新读取配装和市场列表。打开状态栏时，读取超时、尚未读取和队列空闲也有各自的提示。

### 市场任务与解密

本版合并了上游 2.0.5 的领奖筛选、文件解密和配装优化。[上游更新说明](https://github.com/SaltApocalypse/cor3-helper/releases/tag/v2.0.5-salta)

- **修复已完成的委托偶尔漏领奖。** 市场显示一项已接委托可以结算时，插件会直接走领奖步骤，旧的完成记录或小游戏等待记录不会再把它跳过。任务类型选择和到期时间仍然有效。
- **修复文件解密误判算力不足。** 确认换装成功后，如果分析结果把解密算力报为零或空值，插件会尝试打开对应文件一次，以游戏返回的结果为准。配装读取也为慢响应留出了更多时间，相同装备和任务条件下可以复用刚算好的方案。
- **简单解密点得更准。** 插件只在当前小游戏里找解密按钮，支持本地化按钮文字，避开跳过、取消和强制操作。同一小游戏持续停在屏幕上时只处理一次。

### 缓存、断线与账号切换

- **快速重开 C3 会沿用刚读到的数据。** 配装和 Daily 最多复用 5 分钟，远征和无人机最多 1 分钟，市场最多 5 分钟且以实际刷新时间为上限。上一次读取还在进行时，重新打开会接着等同一次结果。面板关闭期间，缓存到期本身不会触发整套重读。需要最新数据时仍可手动刷新。
- **空闲时少检查，服务器慢时少重试。** 账号优先在页面变化、返回游戏页和执行操作前核对，连接稳定时每分钟才做一次本地兜底检查。某个市场到点后仍返回旧数据时，只延长该市场的重试间隔，最长 15 分钟。修复了一个游戏连接过期会把其他连接一起断开的问题。
- **Daily 和无人机状态更可靠。** 重复的登录通知合并为一次 Daily 读取。服务器超时或返回异常时保留上一次有效结果。换号前发出的请求即使晚到，也不会覆盖新会话。Daily 登录凭据只保存在当前游戏页内存中，确认账号后会清理该账号的旧版本地凭据。收到无人机维修回执后，会另外读取最新状态。

### 下载与更新

在本页附件中选择 Chrome 或 Edge 压缩包。已安装 2.1.0 的用户，等当前任务结束，把新包中 `extension` 的内容覆盖到原来加载的目录，在扩展管理页点「重新加载」，然后刷新游戏页。沿用原目录和扩展身份即可继续使用原有设置。

首次安装请解压对应的包，在扩展管理页开启开发者模式，选择「加载已解压的扩展程序」，指向解压后的 `extension` 文件夹。

Chrome 和 Edge 各通过 559 项本地回归测试，上游参考代码通过 448 项测试。中英文界面已在独立浏览器窗口验收。真实账号领奖、小游戏结算和长时间断网恢复仍待实机验证。
